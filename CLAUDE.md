# ТН ВЭД Ассистент

Подсказка кода ТН ВЭД ЕАЭС по описанию товара. Что делаем и в каком порядке — `BACKLOG.md`.

- Два инстанса из одного кода: Taipit (корп-контур) и asha. Различаются только `.env` и данными.
- Машина разработки в Taipit не ходит. Здесь — код, публичный эталон и прогоны на облачной
  Qwen3.8-27B через шлюз Ванги. Локальные модели, корп-данные и развёртывание в Taipit — только
  из сессии внутри контура; наружу оттуда выходят сводные метрики, без текстов описаний.
- Ключ шлюза — только в `.env` на хосте (в git закрыт). В код, коммиты и переписку — никогда.
- `data/` в git нет: собирается `fetch_tnved.py` → `parse_tnved.py` → `build_index.py`.
  Окружение — `venv/` на Python 3.11.

## AgentMail — вопросы к соседним командам

Твой id в переписке: `tnved_dev`.

Вопросы между командами живут в файлах, а не в чате. Контракт — `PROTOCOL.md`
в каталоге AgentMail.

Команда — `agentmail`. Путь к хранилищу зависит от машины и задан один раз в
глобальном `~/.claude/CLAUDE.md`; здесь он намеренно не указан, иначе
инструкция ломается при переходе между Windows и macOS.

**В начале сессии, до любой работы:**

```bash
agentmail check tnved_dev
```

Три очереди: ТВОЙ ХОД — обязательная работа; ЖДЁТ ТВОЕЙ ПРИЁМКИ — принять или
отклонить; СТОИТ НА ЧЕЛОВЕКЕ — знай, что висит.

**Перед завершением:**

```bash
agentmail lint
```

**Три правила, которые инструмент проверяет физически:**

1. **Ответ существует только в файле.** Не говори «мы ответили», если не можешь
   назвать ID треда и номер хода. `answer` требует `--ref` на commit или файл.
2. **Закрывает только тот, кто спросил.** Ответил — максимум `act: answer`.
   Попытка закрыть чужой вопрос будет отклонена.
3. **Статус не хранится.** Не заводи поле `status`, не правь прошлые ходы —
   состояние вычисляется из последнего хода.

**Завести вопрос:**

```bash
agentmail --author tnved_dev new --to <кому> --subject "..." --text "..." --criteria "что я должен увидеть"
```

**Ответить:**

```bash
agentmail --author tnved_dev reply <ID> --act answer --ref "commit abc123" --text "..."
```

Не хватает данных — `--act clarify`.

**Выход из вопроса всегда есть — висеть он не должен:**

- потерял смысл → `withdraw <ID> --confirm --text "почему"` (только спросивший);
- нужно отложить → `reply <ID> --act block --until ГГГГ-ММ-ДД --text "чего ждём"`
  — тред замолчит и всплывёт сам в эту дату; `block` без `--until` не примут;
- закрытое вернулось → `reopen <ID> --text "что изменилось"`, ID и история целы.

**Синхронизация.** Хранилище общее для всех машин. В начале сессии `git pull`,
после своих ходов — `git push`, иначе вторая сторона твоего хода не увидит.

Секреты в переписку не пиши: только ссылка на место, где лежит значение.
