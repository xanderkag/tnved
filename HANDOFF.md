## Выкат

Из рабочей копии (Git Bash), после коммита:

```bash
# 1. Код на хост: ровно HEAD, без CRLF и без неотслеживаемых файлов
git -c core.autocrlf=false archive --format=tar HEAD | ssh kb-docker 'tar -x -C ~/tnved'

# 2. Сверить, что доехало (хеш файла в HEAD и на хосте)
git show HEAD:classifier.py | sha256sum; ssh kb-docker 'sha256sum ~/tnved/classifier.py'

# 3. Пересобрать и поднять только app
ssh kb-docker 'cd ~/tnved && docker compose up -d --build app'

# 4. Дождаться /health 200 и пометить образ коммитом
ssh kb-docker 'curl -s http://localhost:8110/health'
ssh kb-docker 'docker tag tnved:latest tnved:<sha>'
```

`.env` на хосте архивом не перезаписывается (его нет в git). Новые переменные — со значением по умолчанию в `docker-compose.yml`; если по умолчанию нельзя — дописать в `~/tnved/.env` руками, значения в переписку и коммиты не класть. Выгрузка справочника `exports/tnved10_paths_*.csv` в git не входит — лежит на хосте и попадает в образ при сборке.

**Проверка после выката:** пакет из 10 строк с известными кодами (пилот-10: действующий код 10/10, позиция 10/10 на `cd7bcbe`) и `GET /api/codes/export` — 200 и `X-Tariff-As-Of` равен `tariff_as_of` из `GET /api/codes` (26.09: `06.05.2026`, кодов 15 614); выгрузка устарела — 503 с причиной, пересобрать `python export_codes.py`.

## Откат

```bash
ssh kb-docker 'cd ~/tnved && docker tag tnved:<прежний sha> tnved:latest && docker compose up -d --no-build app'
```

Проверено 26.09: `cd7bcbe` → `c06d29f` → `cd7bcbe`, `/health` 200 через несколько секунд. Прежний образ каждого выката записан в STATUS.md («Прежний образ — tnved:…»). Код на хосте после отката остаётся новым — следующий `--build` соберёт его снова.

## Если что-то не так

- **`/health` 503, `mode: degraded`** — не отвечает сервер векторов или паспорт индекса не совпал с моделью: `docker logs tnved | grep -iE 'вектор|embed'`. Сменили сервер векторов — `python check_embeddings.py`.
- **Контейнер падает без трейсбека, Caddy отдаёт 502** — faiss не той версии: процессор kb-docker без AVX, `faiss-cpu` 1.14+ падает с SIGILL. Версия закреплена в `constraints.txt` (1.13.2) — не поднимать.
- **Строки пакета с ошибкой «Модель … не ответила» / «ответ обрезан»** — модель занята или зациклилась: `docker logs tnved | grep '\[llm\]'` (время, токены, `finish`). Обрыв ответа со схемой повторяется один раз сам; повторяется часто — смотреть модель, а не поднимать `LLM_MAX_TOKENS`.
- **«код не выдан: …» в колонке «Ошибка»** — не сбой, а отказ по правилу (несуществующий, снятый или неполный код, описание — только обозначение); причина в тексте.
- **Браузер показывает старый интерфейс** — `static_version` в `/health` должен смениться после выката; `curl -s http://localhost:8110/ | grep app.js` → `?v=<хеш>`.
