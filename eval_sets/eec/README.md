# Решения ЕЭК о классификации — публичный набор для EVAL

195 случаев «подробное описание товара → код», взятых из решений Коллегии ЕЭК
(и Комиссии Таможенного союза) о классификации отдельных товаров. Это официальные
решения, а не заявленные коды, поэтому набор годится как эталон. Товары в нём —
спорные случаи, по которым понадобилось решение Комиссии, так что набор строгий:
точность на нём ниже, чем на обычном потоке строк.

Данные публичные, корп-данных в наборе нет — поэтому он в git, в отличие от
наборов холдинга и SLAI.

## Файлы

- `eec_decisions.xlsx`
  - лист «10 знаков» — 59 случаев с полным кодом, который есть в нынешнем
    справочнике. Колонки «Описание» и «Код ТН ВЭД» — `eval.py` читает лист
    без доработок;
  - лист «все» — все 195 случаев.
- `eec_decisions.jsonl` — те же 195 записей с полями `id`, `decision`, `product`,
  `description`, `gold`, `gold_digits`, `gold_in_current_tree`, `year`, `ocr`.

## Что важно знать при замере

- **Глубина эталона разная.** Решение часто называет только товарную позицию:
  4 знака — 82 случая, 6 — 26, 8–9 — 21, 10 — 66. Сравнивать нужно по префиксу
  длины эталона. Нынешний `eval.py` строки короче 10 знаков отбрасывает, поэтому
  на листе «все» он увидит только их часть.
- **Часть кодов устарела.** Решения идут с 2010 года, номенклатура с тех пор
  менялась. Проверка по справочнику — `gold_in_current_tree`; 29 кодов в нынешнем
  справочнике не найдены.
- **Описание — из пункта 1 решения**, до слов «в соответствии с Основными
  правилами…». Код — из перечня решений на сайте ЕЭК, а не из разбора текста.
  Решения на несколько товаров (с несколькими кодами) и решения о поправках
  в набор не вошли.
- **97 текстов получены распознаванием сканов** (поле `ocr`). В них возможны
  опечатки распознавания — это тоже шум, как в реальных описаниях.

## Откуда и как собрано (28.09.2026)

- Перечень — таблица решений о классификации на eec.eaeunion.org, 252 строки
  до решения № 107 от 18.08.2026.
- Тексты — docs.eaeunion.org: русская версия docx, doc, html или pdf; у сканов
  текст распознан через Vision (macOS). 18 старых решений с закрытого сайта
  eurasiancommission.org взяты из web.archive.org.
- Текст получен у 235 решений из 252; 195 из них дали один код и описание.
- Сырые файлы — в `data/raw/eec/` (в git не лежат).
